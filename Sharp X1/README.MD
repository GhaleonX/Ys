## Startup
Begin the game with ‘Disk A’ in ‘Drive 0’.
Save/Load functions require a ‘User Disk’, which can either use a second disk drive or be swapped out with the ‘Game Disk’ during save/load functions if there is only one disk drive. 


## Controls

- __Numeric Keypad:__ 4-way movement
- __S Key:__ Status
- __I Key:__ Inventory/Equipment
- __Return Key:__ Use Item/Confirm Selection
- __Space Bar:__ Confirm Selection _(or Cancel Save/Load/Format Dialog)_
- __R Key:__ Read Book
- __ESC:__ Pause
- __F1:__ Load
- __CAPS LOCK:__ High-Speed ​​Mode
- __F4:__ Save
- __F5:__ Format Disk

_Notes: Most emulators offer the option to create a ‘blank disk’; alternatively, you can save on top of any existing ‘User Disk’ that’s already formatted for this game._

To talk to stationary NPCs, walk into them. To talk to walking NPCs, let them walk into you.

Combat is best performed when you are NOT centered against your opponent.

> This was thoroughly tested in X Millennium for Windows and Dreamcast. However, there are other X1 emulators which split memory banks differently and may have incompatabilities.
