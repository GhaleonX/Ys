## Ancient Ys Vanished - Omen
- Platform: PC-9801
- Developer: Nihon Falcom
- Original Release Date: 28 August 1987
- English Release Date: 21 June 2026
- Update Release Date: 04 July 2026

### Patching Instructions

1:  Apply “Ys English PC98 Patch” to your Ys PC-98 disk image.

     The unpatched file should match this:	

	- CRC32: 4c98f05a
	- MD5: c2a16667bd11c0a1de30eab5469e2892
	- SHA-1: 53d9894d38b23cab65245584e051b8677709e8e4

     The resulting file should match this:	
     
     - CRC32: 9d19edec
     - MD5: f84e150efc7b0b3027d80aa4b9d12af9
     - SHA-1: ae100a42224c2a6801c1169cfe92b998e9717f23


2: Play the game!

## Converting to D88
> Some PC98 emulators do not support the NFD format, but it's possible to convert your image to a D88 file, which should work with most emulators that don't support NFD. You can convert the NFD to a D88 file with ‘Virtual Floppy Image Converter’.
> 
> Alternatively, you can or use the ‘PC98 NFD to D88’ bps patch, and change the extension of the patched file to .D88
> 
> _This game does NOT work in DOSBox-X._

     The resulting D88 file should match this:	
     
     - CRC32: 2e59bf85
     - MD5: e3a0350fb5babdf0912aa2222b926228
     - SHA-1: 9c847e122aa7dedb84f20583665df77a0c730c69

## Startup
- Begin the game with the ‘Game Disk’ in ‘Drive A’.
- Save/Load functions require a ‘User Disk’ in ‘Drive B’.   


## Controls

- __Numeric Keypad:__ 4-way movement
- __S Key:__ Status
- __I Key:__ Inventory/Equipment
- __R Key:__ Read Book
- __Return Key:__ Use Item/Confirm Selection
- __Space Bar:__ Confirm Selection _(or Cancel Save/Load/Format Dialog)_
- __CAPS LOCK:__ High-Speed mode
- __F1:__ Load
- __ESC:__ Pause
- __F4:__ Save
- __F5:__ Format

To talk to stationary NPCs, walk into them. To talk to walking NPCs, let them walk into you.

Combat is best performed when you are NOT centered against your opponent.
