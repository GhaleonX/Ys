## Startup
Begin the game with the ‘Game Disk’ in ‘Drive A’.
Save/Load functions require a ‘User Disk’. You will be prompted to eject the ‘Game Disk’ and insert the ‘User Disk’ into ‘Drive A’ to save or load data (and subsequently prompted to swap back after doing so to resume the game).  


## Controls

- __Arrow Keys/Numeric Keypad:__ 4-way movement
- __S Key:__ Status
- __I Key/Space Bar:__ Inventory/Equipment
- __R Key:__ Read Book
- __Return Key:__ Use Item/Confirm Selection
- __Space Bar:__ Confirm Selection _(or Cancel Save/Load/Format Dialog)_
- __F1:__ Load
- __ESC:__ Pause
- __F4:__ Save

> Notes: To format a disk, start the MSX2 with the ‘Game Disk’ in ‘Drive A’ while holding the CTRL key

To talk to stationary NPCs, walk into them. To talk to walking NPCs, let them walk into you.

Combat is best performed when you are NOT centered against your opponent.
